# Браузерная проверка

Дополнительная проверка настоящего интерфейса с помощью Playwright. Требует Node.js, пакет `playwright` и Chromium. Эти зависимости нужны только разработчику.

В отдельном окне терминала запустите пустую временную рабочую область:

```bash
python -m sentinel --db data/browser-test.sqlite3 serve --port 8766
```

В другом окне, после установки `playwright` в окружение разработки и его Chromium:

```bash
node tools/browser-smoke.cjs
```

Можно использовать установленный Chrome вместо Chromium Playwright: задайте переменную окружения `PLAYWRIGHT_CHANNEL=chrome` (в PowerShell: `$env:PLAYWRIGHT_CHANNEL='chrome'`).

Проверка ожидает **пустую базу** на порту 8766. Она загружает демо, ищет инцидент, сохраняет решение, проверяет экспорт, отклонённую строку импорта, вывод HTML-подобного текста и мобильную ширину. Остановите тестовый сервер после завершения. Для повторения выберите новую базу.
